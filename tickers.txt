# HOW TO CONFIGURE YOUR TARGET STOCKS (CHOOSE ONE):

# METHOD 1 (RECOMMENDED - Easy to edit anytime via GitHub Gist):
# 1. Go to https://gist.github.com
# 2. Name the file `tickers.txt` and enter your stock tickers (one per line):
#      NVDA
#      AMD
#      PLTR
#      TSLA
# 3. Click "Create secret gist" at the bottom.
# 4. Click the "Raw" button and copy the URL from your browser address bar.
# 5. In your GitHub Repository:
#    Settings -> Secrets and variables -> Actions -> New repository secret
#    - Name: TICKERS_URL
#    - Secret: Paste the Raw Gist URL
#    => Now you can edit your stock list anytime on Gist without retyping!
#
# METHOD 2 (Direct Secret):
# In your GitHub Repository:
# Settings -> Secrets and variables -> Actions -> New repository secret
# - Name: TARGET_TICKERS
# - Secret: NVDA,AMD,PLTR,TSLA
#
# METHOD 3 (Local Testing on your PC):
# Option A: In your .env file:

#           or TARGET_TICKERS="NVDA,AMD,PLTR"
